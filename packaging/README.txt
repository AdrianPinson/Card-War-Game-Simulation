WAR — THE CARD TABLE 1.0.0

Choose the ZIP matching your operating system AND CPU architecture.
Extract the entire ZIP before running. Do not run files inside the ZIP viewer.

BUNDLED: Java is included. Open WarCardTable.exe (Windows), WarCardTable.app
(macOS), or WarCardTable/bin/WarCardTable (Linux).
PORTABLE: install Java 17+ first, then run start-war.cmd (Windows) or
./start-war.sh (Linux/macOS). If your extractor removes executable bits, use
sh start-war.sh. JAVA_HOME can select your Java installation.

Linux desktop libraries: GTK 3 and XTest. Ubuntu 24.04 packages:
libgtk-3-0t64 libxtst6. These operating-system libraries are not bundled.
Packages are unsigned application folders, not installers. Windows/macOS
may prompt before opening downloaded applications. Follow your normal
system policy; these builds are not code-signed or notarized.

No account, API key, network service, or real-money transactions are used.
All 52 cards and all game rules are local. See docs/demo-guide.md for a
short walkthrough, docs/desktop.md for playback, and docs/rules.md for the
precise War variant. Exports go to locations you select in native dialogs.

The console can also run with Java 17+:
java -jar war-simulation.jar help
(Bundled packages keep the JAR in the application's app directory.)

SHA256SUMS.txt lists files inside this distribution; the adjacent download
checksum file lists ZIP hashes. Checksums check file integrity, not publisher
identity. PROVENANCE.json records the source revision and platform.
THIRD_PARTY.md and licenses/ describe dependency and runtime notices.
